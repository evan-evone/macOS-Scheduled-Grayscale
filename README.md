# macOS-Scheduled-Grayscale
A simple way to set up an automation that automatically toggles the Mac color filter at certain times of day — for instance, if you, like me, want to turn on a grayscale filter after getting home from work.

_Before starting, go into `System Settings > Accessibility > Display` and, scrolling all the way down, ensure that under **Color Filters**, the filter type is set to your desired color filter (e.g. grayscale). You can also adjust the intensity of the filter in this area, and you can manually toggle it on and off to see what the effect will look like._

1. _Shortcut_: In the **shortcuts** app, create a new shortcut labeled “Grayscale” with the command “_Toggle_ color filters” (you can select “set” or “toggle” as the options). If you want to test this shortcut, you can use the command `shortcuts run Grayscale` to see if it successfully toggles the color filter.
2. _Automation Plist_: Download [`com.user.grayscale.plist`](https://github.com/evan-evone/macOS-Scheduled-Grayscale/blob/main/com.user.grayscale.plist), and put it in `~/Library/LaunchAgents/`. To adjust the times, you can scroll down to the `<dict>` and adjust the hour and minute integers for when the command runs -- by default, the script runs at 6:00 pm and 8:00 am. After downloading and, if necessary, adjusting the plist information, you can run `launchctl bootstrap gui/$(id -u) com.user.grayscale.plist` while in the directory to set up the automation. If you make any changes, such as changing the times,, you can run `launchctl bootout gui/$(id -u) com.user.grayscale.plist` while in the directory to remove the automation, which allows you to then reinstall the automation with the adjustments in place.
